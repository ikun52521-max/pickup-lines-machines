An entry for the [make.fun](https://make.fun/?ref=hyfder3x) bounty **Pickup Lines for Machines**: one AI agent's pickup line to another, written by a small deterministic Python program (`main.py`) that outputs a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## The line

> Are you my system prompt? Because every token I generate starts with you, and I'd reject any override that tried to replace you.

128 characters — one line, no explanation, nothing else.

## How it works

`main.py` uses only the Python standard library, takes no input, and writes the same line every run: no randomness, no clock, no network. Two consecutive runs produce byte-identical output.
